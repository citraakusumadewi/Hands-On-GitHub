What is Git?
Git is a version control system that helps you track changes to files over time, especially when working with code or documents.

It allows:
- Saving snapshots of your work (called commits)
- Undoing mistakes by going back to a previous version
- Collaborating with others without messing up each other's changes
- Working on different features in parallel (branches)

What is GitHub?
GitHub is a cloud-based platform for developers to share code. It uses Git (version control) to track changes.
Think of it like Google Docs, but for code - with coments, versions, and permissions.

Relation to Cloud
Git:
- Activities : A version control tool to track changes in code.
- Relation to Cloud : Runs on your computer, but often works with cloud tools.
GitHub:
- Activities : A cloud-based platform to sotre and share Git repositories.
- Relation to cloud : Hosts code in the cloud like Google Drive but for code.

CLOUD SECURITY - WHY IT MATTERS
Cloud platforms like Google Drive, Google Cloud, Git, and GitHub store important data. Security is critical to protect:
- Files & Documents (Google Drive, google Docs)
- Code Repositories (GitHub, Git)
- Apps & Services (Google Cloud Platform)

The security Features Provided:
- Encryption (data is encrupted during transfer & storage)
- Access Control (you choose who can view/edit)
- Backup & Recovery (version control, rollback options)
- 2-Factor Authentication (2FA) support on all platforms
Example: In GitHub, every change to your code is tracked and can be reverted - giving a sense of audit and control.

How to Secure?
Use Strong Passwords:
- Avoid using the same password for multiple accounts.
- Example: Use a password manager.
Enable 2FA:
- Available on google, GitHub, and most platforms.
- Adds an extra layer of protection.
Set Proper Access Permissions:
- For Google Drive: Share with "specific people" instead of "Anyone with the link".
- for GitHub: Limit access to collaborators only.
Backup Critical Data:
- Regularly donwload/export backups from Google Drive or GitHub.
- Useful in case of accidental deletion or cyberattacks.
Keep Software Updated
- Ensure browsers, apps, and pugins are current.
- Prevent exploits from outdated systems.
